# Portfolio Builder

**Portfolio Builder** is a browser-based web app for creating, customizing, previewing, and exporting a personal portfolio website. It provides an interactive workspace for editing profile details, skills, projects, and visual design, then turns those choices into a standalone portfolio page that can be shared online.

## Project overview

The app combines content editing and visual design in one place. Changes appear in a live preview, while the finished portfolio can be exported as a self-contained HTML file. Exported files can later be imported back into the builder, allowing the portfolio to be continued and customized without starting over.

The public app is hosted on GitHub Pages. Visitors can open the live site directly in a web browser; no local server or installation is needed to use the published demo.

## Features

- Edit profile information, skills, project details, and portfolio content.
- Preview the generated portfolio and check responsive layouts.
- Choose theme presets and customize typography, colors, layout, cards, buttons, sections, and navigation.
- Save the current editing state in the browser.
- Export a standalone HTML portfolio that can be shared independently.
- Import a previously exported portfolio, review its contents, and confirm before replacing the current data.
- Validate imported portfolio metadata and preserve compatibility through a versioned data format.

## Technology

Built with React, JavaScript, HTML, CSS, and Vite. GitHub Pages hosts the public application and its production assets.
